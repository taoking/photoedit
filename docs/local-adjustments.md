# 局部调整

Phase 7 在 `EditState.localAdjustments` 中保存局部编辑。每个 `LocalAdjustment` 都有独立的 UUID、启用状态、蒙版和曝光/对比度/饱和度；它们不会混入全局 Light 或 Color 参数，因此可随预设 JSON、撤销和「仅粘贴局部调整」一起可靠地保存或复制。

旧版本 JSON 没有 `localAdjustments` 字段时会解码为一个空列表，避免历史预设在升级后失效。

## 渲染顺序

```text
Source → Technical LUT → 全局调整 → 局部蒙版混合 → Creative LUT → transform/crop → HDR 或 SDR 输出
```

每个启用且非零的局部调整先在完整图像上生成调整结果，再以 `CIBlendWithAlphaMask` 与当前图像混合。多个局部调整依数组顺序叠加。坐标始终是未裁切原图的 0…1 归一化坐标，因而 Preview、全分辨率导出和非破坏裁切共享同一蒙版定义。

## 蒙版

- 线性渐变：起点为不透明，终点为透明，可用起点/终点坐标控制方向和过渡。
- 径向渐变：中心、内圆半径和羽化宽度均相对原图短边保存。
- 画笔：拖动采样为归一化点；渲染时按 Preview/Export 的目标尺寸一次栅格化为 alpha bitmap mask，并按归一化几何缓存复用。相邻点小于 0.008 不重复记录，单笔最多 512 点，避免长笔画无界增加 Core Image 图或重建数百个 radial filter 节点。

当前实现优先提供手工渐变和画笔。主体、天空等语义 AI 蒙版不在本阶段范围内，也不会把未验证的系统分割结果伪装成可用功能。

## 人工验证

- 在真机导入 JPEG、HEIF 与 RAW，分别添加线性、径向和连续画笔蒙版，确认局部曝光、对比度、饱和度只影响选区。
- 旋转或裁切后比较 Preview 与全分辨率导出，确认归一化蒙版仍对齐原图内容。
- 用撤销、预设保存/读取和选择性「局部调整」复制粘贴检查多个蒙版的顺序与参数。
- 在 12MP、24MP、48MP 实拍文件上测量长画笔的预览延迟和导出内存；仓库没有可分发的人像/天空语义蒙版样本，这部分不作自动视觉断言。
